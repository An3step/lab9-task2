# Project Description

Кроссплатформенный финансовый калькулятор для расчета сложных процентов. Приложение позволяет рассчитать конечную сумму вклада и прибыль, а также визуализирует рост капитала на графике с помощью Canvas API.

### Key Features
*   **Поля ввода:** Начальная сумма, годовая ставка, срок (годы), капитализация (ежемесячно/ежеквартально/ежегодно).
*   **Валидация:** Проверка ввода на граничные значения и типы данных с выводом ошибок.
*   **Визуализация:** Отрисовка графика роста капитала с градиентной заливкой (Android) или тонкими линиями (iOS/Linux).
*   **Интерактивность:** Интерактивные графики с масштабированием (Web), поддержка сенсорного ввода и мыши.
*   **Интернационализация:** Поддержка русского, английского и китайского языков.

### Tech Stack
*   **UI:** Compose Multiplatform
*   **Графика:** Compose Canvas API
*   **Валидация:** Кастомные Kotlin-классы для математических вычислений
*   **Асинхронность:** Kotlin Coroutines

---

## Platform-Specific UI Requirements

*   **Android:** `TextField` для ввода, `Slider` для настройки параметров, кнопки Material 3. График с градиентной заливкой.
*   **iOS:** `Picker` вместо `Slider` (где уместно), плоские кнопки без теней. График с более тонкими линиями.
*   **Linux:** Классические `SpinBox`-элементы для числового ввода, простые графики без градиентов. Фиксированные размеры элементов.
*   **Web:** Адаптивные формы ввода, интерактивные графики (поддержка зума через жесты/колесико мыши).

## How to Build

Для сборки проектов необходимо:
* **Android Studio** (Hedgehog или новее).
* **Xcode** (для iOS).
* **JDK 17+**.

### Build Commands
*   **Desktop (Linux):** `./gradlew :composeApp:run`
*   **Web:** `./gradlew :composeApp:wasmJsBrowserRun`
*   **Android:** `./gradlew :composeApp:assembleDebug`

## Testing

Проект содержит модульные, UI и интеграционные тесты, покрывающие вычислительную логику и графический интерфейс.

*   **Модульные тесты:** Проверка математической точности расчетов (сложные проценты), валидации ввода (пустые поля, отрицательные числа).
*   **UI-тесты:** Проверка отрисовки графика (Canvas), отображения ошибок валидации, реакции слайдеров/пикеров.
*   **Интеграционные тесты:** Сквозной сценарий работы: ввод данных -> расчет -> проверка корректности графика и итоговых сумм.

### Run Tests
`./gradlew allTests`
